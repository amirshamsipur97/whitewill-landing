## 2. The bug that matters most for SEO recovery

From 2026-08-30 (`ad30b67`) to 2026-09-14 (`692e587`), every H2/H3 in the
prerendered HTML of all articles was `<hundefined>[object Object]</hundefined>`:
the heading renderer used marked's old `(text, level, raw)` signature and marked 18
passes one token object. Browsers looked fine because React re-renders `#root`;
crawlers' first fetch saw no headings for two weeks. Fixed and the build now throws if
it recurs.

**Lesson:** verify SEO changes in the RAW prerendered HTML (curl + parse `<article>`),
never only in a browser or by title/meta/JSON-LD, which come from other code paths.
Expect some article ranking recovery once Google recrawls; watch it.

## 3. Rules learned this week (also in memory)

- Title/keyword changes: one page per intent, and verify ownership first (query `insights.seo_title` + `src/seoRoutes.mjs`) so pages do not cannibalize.
- Evidence from one language does not transfer to another.
- Price per m²: compute price / total_area_sqm, median, never the stored column.
- `leads.created_at` is unreliable; use `inserted_at`.
- Arabic: «عمان» alone means Amman, Jordan in Google. Write «سلطنة عُمان» / «مسقط».
- zsh: never name a shell variable `path`.
- Before claiming "not in Google": read GSC Chart + Pages CSVs first.
