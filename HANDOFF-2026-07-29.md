## 2. 🔴 THE ATTRIBUTION TRAP — read before any ads analysis

**`leads.utm_campaign` is EMPTY for C1**, because C1 was never UTM-tagged
(only C6/C7 were). Reading that column makes the whole paid programme look
like it produced almost nothing. It is wrong.

The real attribution is Google **auto-tagging**, which writes
`gad_campaignid` + `gclid`/`gbraid` into the landing URL, and
`attribution.js` stores it in **`raw_data->>'page_url'`**. Classify with:

```sql
case when raw_data->>'page_url' like '%24001281094%' then 'C1'
     when raw_data->>'page_url' like '%24025469441%' then 'C6' ... end
```

**True 30-day picture:** organic/direct **33** · C1 **6** · C6 **1**.
C1 spent $1,350 → **real CPA $225**.

"No leads for days" was arithmetic, not breakage: at $225 CPA and $30/day you
get one lead per ~7 days. At the old $90/day it was one per ~2.3 days.

## 4. Gotchas that cost real time

1. **The header nav is React-only.** It never reaches the static HTML. The
   footer block (`footerSeoLinks.mjs`) is what a crawler sees, on all 614
   pages. This is how `/schools` was found to have exactly one inbound link
   and **zero static ones**.
2. **A 0×0 node reports `visibility: visible`.** I twice mis-reported the
   popup as opening on pages where it does not. **Measure
   `getBoundingClientRect()` + opacity**, never visibility alone.
3. **`curl -X POST` breaks Apps Script.** It 302s to
   `script.googleusercontent.com/macros/echo` and serves the body only to a
   **GET** on the echo URL. `-X` pins the method across the redirect and
   returns Google's "page not found" HTML. Correct form:
   `curl -s -L -H "Content-Type: application/json" -d '{...}' "$URL"` (no `-X`).
4. **Web app access must be "Anyone", NOT "Anyone with Google account"** —
   the latter redirects to accounts.google.com and is indistinguishable until
   you follow the redirect chain. "Authorize access" is a separate thing.
5. **Thumbs must stay OUT of `src/assets/projects/`** — that glob treats the
   first file by natural sort as the cover, so a thumb there would appear as a
   gallery image and change the cover.
6. **Two prerenderers keep their own `footerLinksHtml()`** —
   `prerender-routes.mjs` and `prerender-insights.mjs`. Change both.
