# Full technical SEO audit, 768 built pages (2026-08-30)

Owner reported no ranking on a French IP for `buy property in muscat` and
`buy property in oman`, asked for a full SEO package and for bug hunting.

## The honest frame, stated first

**"Rank in every country" is not something any implementation delivers.**
Ranking is competitive and geo-personalised. What an audit CAN do is find and
remove every technical defect standing in the way, and say plainly where the
remaining ceiling is. That is what this is.

## What was already correct, and is worth not re-auditing

Measured across all 768 built pages, not sampled:

| check | result |
|---|---|
| **hreflang reciprocity** | **1,114 links, 0 broken targets, 0 one-way.** Google discards non-reciprocal hreflang entirely, so this is the single biggest international failure mode and the site does not have it. |
| canonical present | 768 of 768 |
| canonical inside its own hreflang set | 100% |
| `noindex` | zero pages |
| missing `<title>` / description / `<h1>` | zero |
| structured data | present on every page |
| robots.txt | open, only `/insights-admin` and `/api/` disallowed |
| duplicate unit titles | 53 groups, **all consolidated to one canonical**, so not duplicate content |
| trailing slash | `/buy` and `/buy/` both 200 but serve the **same canonical**, so Google consolidates. Not a defect. |
| `/property/:id` 307s | **deliberate and documented**: sold units 301 to the project page, available units 307 to the portal because that state changes. Do not "fix" these. |

## Defects found and fixed

### 1. Forty article pages shipped TWO `<h1>` tags 🔑

The page chrome prints the article title as `<h1>`, and 40 of 168 rows (17
slugs) also open their `body_md` with a markdown `# Title` line, which `marked`
rendered as a second, identical `<h1>`.

**It only ever broke the static shell, which is the version a crawler reads.**
The client renderer (`components/insights/Markdown.jsx`) has always mapped h1
to h2, so a human never saw it, and it survived unnoticed until this audit.

Fixed in `prerender-insights.mjs` with a `marked.Renderer` that demotes h1 to
h2, matching the client. Covers any future article that includes its own title
line, with no row edit. **40 → 0.**

### 2. Every unit page's meta description was truncated by Google

478 unit descriptions averaged 181 characters and topped out at 193. Google
cuts around 160, so the tail, which carried the freehold and residency line and
the actual selling point, never appeared in a single result.

Rewritten tighter in `prerender-routes.mjs`, most valuable facts first.
**476 over-length → 0**, now averaging 137 and capped at 149.

### 3. 105 unit titles quoted prices in baisa

Titles read `OMR 66,592.63` because some developer files carry fractional
prices and `fmtOmr` passed them straight through. That reads as a spreadsheet
export, not a price, and it lengthened the title.

`fmtOmr` now rounds to whole rials. Display only, the stored value is
untouched, and the rounding is immaterial on a six-figure price. **105 → 0.**

### 4. Sixteen route and three article descriptions ran long

All shortened without losing a fact. **496 over-length pages → 0.**

🚨 **One of them was a factual error, not just length:** the fa article on
converting Oman prices to Iranian money said «۶۱٬۶۳۵ ریال عمانی (حدود ۱۲۵ هزار
دلار)». The correct conversion is **USD 160,300**. A wrong currency conversion,
on the page whose whole subject is currency conversion.

## Still open, and it needs the owner

### apex → www is a 307, not a 308

Confirmed again today: `https://irfaninvest.com/` returns **307 temporary**.
`vercel.json` has the rule with `permanent: true`, but a Vercel **domain-level**
redirect fires first and wins. A temporary redirect tells Google not to
consolidate, so apex and www keep competing.

**I cannot fix this.** `vercel domains inspect` returns "You don't have access
to the domain" and the API returns 403. Fix in Vercel → Project → Settings →
Domains: remove or repoint the apex redirect so the `vercel.json` 308 takes
over. Open since 18 August.

### The 478 unit pages exist in English only

They carry no hreflang because there is no other language to point at. That is
62% of the site's pages available to English searchers only, while the buyers
are Persian, Arabic and Russian speakers. Localising them is a real project,
not a fix, and it should be a deliberate decision rather than a side effect.

## Where the actual ceiling is

The technical foundation is now clean, and it was already better than most.
**A technically clean site that does not rank internationally is almost always
short on authority, not on tags.** The competitors ranking for the Persian and
English terms are content and migration businesses with years of regional
links. We have none of that, an unclaimed Google Business Profile, and a
competitor who has named their profile the exact target keyword.

⚠️ **The Semrush connector could not be used to quantify this.** Its
`execute_report` tool rejects the params object through this harness
("cannot unmarshal string into ... map[string]interface {}"), so every report
fails. Backlink and authority numbers need to be pulled from the Semrush UI
until that connector is fixed.

Measure ranking in **GSC → Performance**, filtered by query, with a country
breakdown. A VPN spot check is not a measurement.
