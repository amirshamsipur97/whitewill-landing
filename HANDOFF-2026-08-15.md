1. Parse file (pypdf/openpyxl). Match project in Supabase `owgvrxipqlusepozlujv`, table `project_units` (RLS OFF, writes are instantly live).
2. `UPDATE … SET availability_status='sold' WHERE project_id=X` (NEVER delete), then INSERT fresh rows mirroring that project's existing conventions (unit_no internal-only, never displayed; floor_label/layout_type/view vocab per project; internal vs total vs garden conventions differ per project, check old rows first).
3. Update `src/data/projectDetails.js` (priceFrom/units/bedrooms/section bodies ×4 langs) + any hardcoded numbers (grep!).
4. Check site-min (see §0) and sweep if moved. Update affected articles via edge fn full-row upsert (scratchpad meta.json + publish.mjs pattern) or targeted service-role SQL.
5. `vercel deploy --prod --yes`, verify: /buy/<slug> AggregateOffer, sample /property/:id title, sitemap count, zero stale prices.
6. Log to Google Sheet "Keywords-Ads" tab **Insights** (Apps Script webhook, secret in auto-memory `whitewill-project-refs`) + update auto-memory.
